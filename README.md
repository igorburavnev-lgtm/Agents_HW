# AI Coding Agents — Домашнее задание №3

## Структура репозитория

В проекте реализованы два независимых прогона AI-агентов по заданиям №1–4.

### 1. DeepSeek Harness
Результаты работы первого агента находятся в ветке **`deepseek-results`**.
- Исходный код: папка `agent-deepseek/`
- Документация: `ANALYSIS.md`, `REQUIREMENTS.md`, `MODERNIZATION.md`, `FEATURE_REQUIREMENTS.md`, `FEATURE_REPORT.md`

### 2. OpenCode
Результаты работы второго агента находятся в ветке **`opencode-results`**.
- Исходный код: папка `agent-opencode/`
- Документация: `ANALYSIS.md`, `REQUIREMENTS.md`, `MODERNIZATION.md`, `FEATURE_REQUIREMENTS.md`, `FEATURE_REPORT.md`

### Сравнительный анализ
Отчеты по заданию №5 (сравнение агентов) будут добавлены в эту ветку (`main`) в файлах `COMPARISON.md` и `AGENT_REPORT.md`.
