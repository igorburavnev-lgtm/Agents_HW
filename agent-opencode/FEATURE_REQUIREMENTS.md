# Требования к новой функциональности: виртуальный инвестиционный портфель (FEATURE_REQUIREMENTS.md)

Требования проверяемые. Нумерация FR-P-XX.

## Функциональные требования

### FR-P-01. Создание портфеля
- **Описание**: Пользователь должен иметь возможность создать виртуальный портфель. Портфель должен быть связан с пользователем.
- **Проверка**: Создание через API возвращает 201, портфель сохраняется в БД.

### FR-P-02. Добавление позиции в портфель (покупка)
- **Описание**: При покупке акции в портфель создается/обновляется позиция (Position/Holding) с количеством и средней ценой покупки. Также должна фиксироваться транзакция покупки.
- **Проверка**: После покупки количество позиции увеличивается, создается транзакция типа BUY.

### FR-P-03. Продажа позиции
- **Описание**: При продаже акции из позиции уменьшается количество. Нельзя продать больше, чем имеется в позиции.
- **Проверка**: При продаже валидного количества позиция уменьшается/удаляется при обнулении; при продаже больше имеющегося возвращается ошибка (400).

### FR-P-04. Расчёт текущей стоимости портфеля
- **Описание**: Система должна предоставлять расчет текущей стоимости портфеля на основе текущей цены акций (Share.last_price).
- **Проверка**: Эндпоинт портфеля/расчета возвращает текущую стоимость, рассчитанную по позициям.

### FR-P-05. Расчёт P&L (прибыль/убыток)
- **Описание**: Система должна рассчитывать реализованный/нереализованный P&L по позициям и/или по портфелю.
- **Проверка**: Возвращается значение P&L (profit/loss) для позиции/портфеля.

### FR-P-06. Просмотр позиций и транзакций
- **Описание**: Пользователь должен иметь возможность просматривать список позиций и историю транзакций своего портфеля.
- **Проверка**: API возвращает позиции и транзакции, привязанные к портфелю пользователя.

## Граничные случаи
- **FR-P-07**: Попытка продать больше, чем есть в позиции - должна возвращать ошибку валидации (400).
- **FR-P-08**: Операции с несуществующей позицией/портфелем - корректная обработка ошибок.
- **FR-P-09**: Покупка при отсутствии цены акции - обработка (либо требование указать цену, либо ошибка).
