# Модернизация проекта (MODERNIZATION.md)

## 1. Актуальность зависимостей

Текущие версии в `requirements.txt` в основном из 2023 года. Для Python 3.11+ требуется обновление ряда пакетов (Django, DRF, Celery, psycopg, redis, grpc/protobuf и др.). Также в проектах часто переходят с `psycopg2-binary` на `psycopg[binary]`.

Предлагаемые обновления (основаны на совместимости с Python 3.11+ и современными версиями на момент подготовки):

## 2. План модернизации
1. Обновить `requirements.txt` под Python 3.11+ с учетом вышеприведенных версий.
2. Исправить настройки и импорты, мешающие запуску (ALLOWED_HOSTS, SECRET_KEY при необходимости для тестов, DATABASES при желании переключить на sqlite для простоты запуска, CELERY_BROKER_URL, возможные проблемы с путями).
3. Привести код к совместимости с обновленными версиями (проверить импорты, использование API).
4. Устранить явные проблемы (опечатки, None-проверки там, где критично для запуска).
5. Прогнать `check`, `migrate`, запустить/остановить `runserver`, добавить тесты, запустить тесты.
